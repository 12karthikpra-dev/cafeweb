# ☕ Vibes Café - Customer Website

This repository contains the standalone **Customer Website** for Vibes Café.

## 🚀 Quick Start
1. Double-click **`start_customer.bat`** (or run `npm install` and `node server/app.js`).
2. Open your browser to: **http://localhost:3000/**

## 📄 Pages Included
- **Home**: Sanctuary overview, ambiance description, acoustic & seating highlights.
- **Menu & Online Ordering**: Interactive item catalog with slide-over cart, item modifiers, and live checkout.
- **About Us**: Purpose of the café, founder spotlight, and worker team profiles.
- **Branches & Reservations**: Branch directory & 1-click table booking.
- **Gallery**: Filterable photo gallery.
- **Contact**: Direct customer message inquiry form.
- **Reviews & Complaints**: Public review submission, star rating, live feedback feed, and team responses.
